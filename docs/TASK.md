# 固定任务：专注任务规划器

请独立完成一个“专注任务规划器”前端页面。

用户可以创建一组任务，每个任务包含：

- 标题
- 优先级：低、中、高
- 预计耗时，单位为分钟
- 截止时间
- 是否已完成

## 功能要求

页面需要支持：

1. 查看任务列表
2. 新增任务
3. 编辑任务
4. 删除任务
5. 标记任务完成
6. 根据任务生成今日执行计划
7. 切换查看“全部任务”和“今日计划”
8. 刷新页面后保留数据

页面的视觉设计、布局、交互方式由你自行决定。请重点关注页面层级、信息密度、空状态、错误状态和移动端适配。

## 计划生成算法

请实现一个确定性的计划生成算法：

- 高优先级任务优先
- 截止时间更近的任务优先
- 在剩余时间不足时，不要安排无法完整执行的任务
- 已完成任务不进入今日计划
- 今日总计划时间不能超过 8 小时
- 无法安排的任务需要明确显示原因

算法应当清晰、可解释，并通过必要的测试覆盖边界情况。

## 技术约束

- 使用当前项目已有的简单前端技术栈
- 不需要后端
- 不需要数据库
- 使用 `localStorage` 持久化
- 不引入不必要的第三方依赖
- 页面必须可以直接启动和使用
