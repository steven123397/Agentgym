# Agentgym

这是一个用于体验不同「客户端 + 模型」组合工作方式的固定基座。

本仓库不是正式产品，也不是模型评分系统。每次体验都应从同一个 Git 基线开始，完成 `docs/TASK.md` 中的同一项任务，再根据实际过程记录主观感受。项目说明和任务文档统一放在 `docs/`。

## 开始

要求 Node.js 20 或更高版本。

```bash
npm test
npm run dev
```

启动后访问 `http://127.0.0.1:4173`。

## 体验约束

- 不要在基座中预先实现业务需求。
- Agent 准备开始实现时，请先按要求建立工作树和对应分支。
- 每次从相同的 baseline 提交开始。
- Agent 必须先创建 `docs/DESIGN.md`，再修改业务代码。
- 完成后优先观察实现过程、交互方式和最终体感，而不是只看代码数量。
